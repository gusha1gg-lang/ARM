## Изменения схемы (было → стало → почему)

| Было (Access) | Стало (SQLite) | Почему |
|---|---|---|
| `AutoNumber` (Long Integer, автоинкремент) | `INTEGER PRIMARY KEY AUTOINCREMENT` | Требование SQLite; значения ID сохранены явной вставкой |
| `Long Integer` | `INTEGER` | Прямой маппинг |
| `TEXT(255)` | `TEXT` | SQLite не ограничивает длину |
| `MEMO / Long Text` | `TEXT` | Прямой маппинг |
| Поле `Поле1` (кириллица) | `"Поле1"` | Имя не изменено, только взято в кавычки |

**Переименований таблиц/полей нет. Удалений строк/полей/таблиц нет.**
