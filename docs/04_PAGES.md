### `/Addipt4.aspx` — добавление

Поля и подписи — дословно из оригинала, в том же порядке:

`Номер пролета`, `Название участка`, `Номер площадки`, `Ось`, `Номер пл. или логин TS`,
`IP адрес`, `Основной шлюз`, `MAC адрес`, `PC/TS`, `Телефон`, `Монитор`, `Принтер`,
`ИБП`, `Модем`, `CISCO`, `Описание` (многострочное).

Валидация (воспроизведена 1-в-1):

| Правило | Сообщение |
|---|---|
| `Prolet` обязательно | «Требуется номер пролета» |
| `Prolet` — целое 0…10000 | «Номером пролета должно быть число» |
| `Oc` обязательно | «Недопустимый формат данных» |
| `Oc` — целое 0…10000 | «Введите число, чтобы указать ось» |
| Дубликат `KE` в 4 таблицах | «КЕ с таким номером уже существует, ты уверен что желаешь сохранить?» |
| Похожий `Monitor` (`LIKE %…%`) | то же сообщение (текст оригинала) |
| Похожий `Printer` (`LIKE %…%`) | то же сообщение (текст оригинала) |

При срабатывании проверки дубликатов кнопка «Сохранить» заменяется на «Все равно сохранить» —
как в оригинале. Пустые значения не проверяются (в ASP.NET `ValidateEmptyText` по умолчанию выключен).

### `/Edit.aspx?id=N` — редактирование и удаление

- GET: форма заполняется значениями записи (те же поля и порядок).
- POST «Сохранить»: обновление, редирект на `/main.aspx`.
- POST «Все равно сохранить»: обновление в обход предупреждений о дубликатах.
- POST «Удалить»: `DELETE FROM IPaddress4 WHERE IDPC=?`, редирект на `/main.aspx`.
- Дубликаты проверяются с исключением текущей записи (`IDPC<>?`) — как в оригинале.

### `/ReportExist.aspx?KE=…` — поиск КЕ

- Три независимых результата, как в оригинале: ТЭСЦ4 (`IPaddress4`), АБК (`IPAddressUch` + `NameUchastok`),
  ТЭСЦ5 (`IPaddress5`). Совпадение — `LIKE %KE%`.
- Пустые результаты не отображаются (в оригинале `GridView.Visible=false`).
- Состав колонок — дословно из SQL оригинала.
- Найденные записи не редактируются (в оригинале тоже — только просмотр).

### Навигация

Восстановлена структура `MainMasterPage.master`: баннер `img/KPK.jpg`, тёмное меню
(Рабочие места → ТЭСК ТБД / ТЭСЦ 5 / АБК / Все цеха; Все ярлыки; Настройки; CISCO;
Телефоны; Web Navigator; Видеонаблюдение). Названия разделов и вложенность не изменены.

Разделы, ещё не перенесённые, отдают страницу 404 с пояснением «Этот раздел ещё не перенесён».

### Отклонения от оригинала (все — осознанные)

| № | Отклонение | Причина |
|---|---|---|
| 1 | Кнопка «Добавить» и значок редактирования видны `editor` и `admin`, а не только администратору | Требование многопользовательского режима (роль `editor`) |
| 2 | SQL с параметрами (`?`) вместо конкатенации строк | Безопасность (SQL-инъекции); поведение выборок не изменилось |
| 3 | CSRF-токен во всех формах, при отсутствии — `400` | Безопасность |
| 4 | Удаление подтверждается диалогом `confirm()` | Защита от случайного удаления; в оригинале подтверждения не было |
| 5 | При «Все равно сохранить» нечисловые `Prolet`/`Oc` всё равно отклоняются | В оригинале такой ввод приводил к ошибке ODBC; теперь понятное сообщение |
| 6 | Вёрстка на CSS-классах вместо inline-стилей ASP.NET | Единый стиль и адаптивность; цвета оригинала сохранены |
| 7 | Меню — CSS-выпадающее вместо `menu2.css` | Совместимость с современными браузерами; состав и порядок пунктов те же |
| 8 | Убрана отладочная ветка `throw` в `catch` | В Flask ошибки обрабатываются штатно |
