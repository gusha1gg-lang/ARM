## 5. Что сохранено 1-в-1

* URL legacy-страниц (`.aspx`, `.htm`), включая `?SPRType=`, `?id=`, `?sort=`.
* Навигация `MainMasterPage.master`: «Рабочие места» (ТЭСК ТБД / ТЭСЦ 5 / АБК / Все цеха),
  «Все ярлыки», «Настройки», CISCO, «Телефоны», «Web Navigator», «Видеонаблюдение».
* Названия разделов, заголовки страниц, подписи полей и кнопок (включая «Удалить епт»).
* Состав колонок и порядок строк — по тем же SQL-запросам, что в оригинале
  (включая отсутствие `ORDER BY` там, где его не было).
* Цвета GridView/таблиц, иконки (`buttonedit.png`, `load.png`, `cross.png`, `save.png` и др.).
* Тексты ошибок и валидаторов (например, «А вот и не угадал. Доступ ограничен.»,
  «Номером пролета должно быть числом»).

Факты legacy, сохранённые без «исправлений»:

* `JR.aspx.cs`: счётчик `i` не увеличивается — все строки белые (так и в оригинале).
* `SPR_CISCO.aspx` без `SPRType` показывает справочник камер; первая запись по
  `ORDER BY IP_CISCO` имеет пустой IP.
* `spr_shop.aspx.cs`: проверка админа была закомментирована — в новой версии доступ
  сужен до `editor`/`admin` (осознанное отклонение).
* Ссылка «Настройка ODBC» ведёт на отсутствующий `Настройка ODBC.htm` — как в оригинале.
* `Webnav.aspx` содержит логины/пароли стендов — содержимое страницы не изменялось.
* `.htm` ссылаются на отсутствующий `editdata.mso` — как в оригинале.

## 6. Сводка отклонений (все осознанные)

Полные таблицы — в `docs/04_PAGES.md` и `MIGRATION_LOG.md` по каждой партии.

| Категория | Отклонение | Причина |
|---|---|---|
| Роли | Запись доступна `editor` и `admin`, а не только админу | Требование многопользовательского режима |
| Роли | Новая таблица `users`, пароли — PBKDF2 | Безопасность; в Access пароль был открытым |
| Безопасность | Параметризованный SQL вместо конкатенации | SQL-инъекции |
| Безопасность | CSRF-токены во всех формах | Защита от подделки запросов |
| Безопасность | Проверка расширения и размера загружаемых картинок | Ограничение 4 МБ как в оригинале |
| Поведение | `POST → redirect` (PRG) и сообщения об успехе | Единый стиль, нет повторной отправки формы |
| Поведение | `confirm()` перед удалением | Защита от случайного удаления |
| Поведение | Некорректный `id` → `400`, отсутствующий → `404` | В оригинале — ошибка ODBC/белая страница |
| Поведение | Понятные сообщения валидации (пролет/ось, камера) | В оригинале запись молча не добавлялась |
| Файлы | Ярлыки отдаются как вложение (`attachment`) | Сохранение смысла кнопки «Скачать» |
| Визуал | CSS-классы вместо inline-стилей ASP.NET, адаптивность | Современный вид; структура и цвета сохранены |
| Визуал | Обёртка `.legacy-static` с горизонтальной прокруткой | Широкие Excel-таблицы не ломают макет |
| Статика | `asp:HyperLink`/`asp:Label` → `<a>`/`<span>` | Без ASP.NET серверные контролы не работают |
| Статика | Кодировка `.htm` в `Content-Type` | Файлы в windows-1251/1252 |
| Структура | Все страницы в общем макете `base.html` | Сохранение Master Page |
